# sulatextemplate
Очень простой темплейт для LaTex по правилам оформленя работ Satbayev university
Есть создание списка литературы по ГОСТ, который указан в стандартах. Чаще всего Ваши проверяющие будут игнорировать все стандарты, так как сами их не знают, так что советую взять вам распечатку стандартов и тыках их туда носом, по-другому они не понимают (относится к стандартам университета и списка литературы).
